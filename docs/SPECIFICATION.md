## 1. プロジェクト概要

| 項目 | 内容 |
|------|------|
| アプリ名 | こんやのきぶん |
| キャッチコピー | 気分で決まる夜ごはん |
| コンセプト | **グルメ版アキネーター** — 2〜3問の気分ベースの質問で今夜の外食先をズバリ言い当てる |
| ターゲット | 夜ごはんが決まらない20〜30代の日本在住ユーザー |
| マスコット | **きぶんくん** — 三日月猫のシェフ。5つの表情で案内する |
| ハッシュタグ | #こんやのきぶん #きぶんで夜ごはん |

### デザイン3原則
1. **トップ画面 = シンプル。** 余計な説明は削ぎ落とし、3秒で始められる
2. **質問画面 = 楽しい。** 選ぶこと自体がエンタメ。きぶんくんが話しかけてくる
3. **結果画面 = ドラマチック。** アキネーター的「ズバリ！」の演出で感動を生む

## 5. マスコットキャラクター「きぶんくん」

### 基本情報
- **モチーフ:** まん丸猫のシェフ。シェフ帽、赤いネッカチーフ、金の星型フォーク
- **性格:** 食べることが大好きすぎて人の食べたいものまで当てられるようになった猫
- **カラー:** ゴールデンイエロー(#F5C542)ボディ、ブラウン(#5C3A1E)輪郭

### 5つの表情

| 表情 | 画像 | 使用場面 | きぶんくんの台詞 |
|------|------|---------|---------------|
| `normal` | kibun-normal.webp | トップ画面 | 「今夜なに食べる？」 |
| `thinking` | kibun-thinking.webp | Q1表示、解析中 | 「うーん、まずは…」 |
| `excited` | kibun-excited.webp | Q2表示 | 「いいね！それで…」 |
| `confident` | kibun-confident.webp | Q3表示、Reveal直前 | 「見えてきたぞ…！」 |
| `tada` | kibun-tada.webp | 結果Reveal | 「今夜はこれでしょ！」 |

### 7つのアニメーション

| アニメーション | 動き | 使用場面 |
|-------------|------|---------|
| `float` | 上下にふわふわ浮遊(3s) | トップ画面 |
| `bounce` | ぴょんと跳ねる(0.5s) | 質問遷移時 |
| `growConfident` | 拡大ドヤ顔(0.8s) | Reveal直前 |
| `celebrate` | スピン＋拡大(0.8s) | 結果Reveal |
| `analyzing` | 高速左右揺れ(0.2s) | 解析中 |
| `shrink` | 縮小(0.3s) | 結果0件時 |
| `none` | 静止 | デフォルト |

## 6. 質問ツリー設計

### アーキテクチャ
v1のスコアリング方式（4軸×固定5問）から、**分岐ツリー方式**に全面刷新。
ユーザーの回答に応じて質問が分岐し、2〜3問でエンドポイント（結果）に到達する。

### Q1: 今夜はどんな気分？（7ルート）

```
🥩 ガッツリお肉！        → 肉ルート（Q2: 焼肉/ステーキ/焼き鳥/ハンバーガー）
🍱 和食で落ち着きたい    → 和食ルート（Q2: 寿司/天ぷら/定食/和食）
🍜 麺をすすりたい        → 麺ルート（Q2: ラーメン/うどんそば/パスタ/お好み焼き）
🌍 海外気分を味わいたい  → 海外ルート（Q2: イタリアン/中華/韓国/アジアン/カレー）
🍻 とりあえず飲みたい    → 飲みルート（Q2: 居酒屋/バー/焼き鳥/女子会）
🥗 軽めでいい            → 軽めルート（Q2: カフェ/ヘルシー/麺）
🎲 おまかせで！          → おまかせルート（Q2: コスパ/映え/完全ランダム）
```

### 結果パターン数: 30+

各エンドポイントは以下を持つ:
- **genreIds**: マッチするジャンルID（優先順、複数可）
- **resultLabel**: 結果の表示名（例:「焼肉（カジュアル）」「こってりラーメン」）
- **resultDescription**: キャッチコピー
- **budgetLevel**: 予算レベル（low/medium/high/any）
- **q4Options**: 利用可能なこだわりチップ
- **siblingHint**: 「こっちもいいかも」の兄弟結果

## 8. ホットペッパーグルメAPI連携

### エンドポイント
`http://webservice.recruit.co.jp/hotpepper/gourmet/v1/`

### APIルート (app/api/restaurants/route.ts)

| パラメータ | 型 | 必須 | 説明 |
|----------|---|------|------|
| lat | string | △ | 緯度 |
| lng | string | △ | 経度 |
| range | string | × | 検索範囲 1-5（デフォルト: 3） |
| genre | string | △ | ホットペッパージャンルコード |
| keyword | string | △ | フリーテキスト検索 |
| budget | string | × | 予算コード（B001〜B014） |
| count | string | × | 取得件数（デフォルト: 5） |
| Q4フラグ | string | × | private_room, free_drink, midnight 等 |

### 予算レベル → APIコード変換

| レベル | 範囲 | APIコード |
|-------|------|----------|
| low | 〜2,000円 | B001,B002,B003 |
| medium | 2,001〜5,000円 | B003,B004,B005,B006 |
| high | 5,001円〜 | B006,B008,B010,B012,B014 |
| any | 指定なし | (null) |

### Q4こだわりチップ（7種）

| チップ | 表示名 | APIパラメータ |
|-------|-------|-------------|
| private_room | 個室あり | private_room=1 |
| late_night | 23時以降OK | midnight=1 |
| all_you_can_drink | 飲み放題 | free_drink=1 |
| lunch | ランチあり | lunch=1 |
| card_ok | カード可 | card=1 |
| non_smoking | 禁煙席あり | non_smoking=1 |
| parking | 駐車場あり | parking=1 |

### 5段階フォールバック

```
Step 1: 全条件（genre + keyword + budget + Q4フラグ + range）
  → 3件以上 → 表示
  → 不足 ↓

Step 2: keyword を除去、genre のみで再検索
  → 3件以上 → 表示（「条件を緩めました」通知）
  → 不足 ↓

Step 3: Q4フラグを全除去して再検索
  → 3件以上 → 表示（「条件を広げました」通知）
  → 不足 ↓

Step 4: range を段階的に拡大（初期値 → 5まで）
  → Steps 1-3 を繰り返し
  → 不足 ↓

Step 5: 最大rangeの結果をそのまま返却（0件でも）
```

### 移動手段 → 検索範囲

| 移動手段 | range | 距離 |
|---------|-------|------|
| 🚶 徒歩 | 2 | 500m |
| 🚲 自転車 | 3 | 1km |
| 🚃 電車 | 4 | 2km |
| 🚗 車 | 5 | 3km |

### ガイドライン準拠
- クレジット表記: ホットペッパーバナー画像(88x35px) + テキストリンク
- 画像利用時の「画像提供：ホットペッパー グルメ」表記

## 13. 状態管理

### useQuizState フック

```typescript
{
  pathStack: string[]                           // 訪問したノードIDの履歴
  currentNodeId: string                         // 現在の質問ノードID
  answers: Record<nodeId, optionId>             // 回答マッピング
  answerLabels: Record<nodeId, {emoji, label}>  // 表示用の回答情報
  endpoint: EndpointNode | null                 // 到達したエンドポイント
}
```

| メソッド | 動作 |
|---------|------|
| `advance(option)` | 次の質問へ進むか、エンドポイントに到達 |
| `goBack()` | pathStackをpopして前の質問に戻る |
| `reset()` | Q1に戻してリセット |

## 14. /play ページのフェーズ管理

1ページ内で4つのフェーズを`useState`で切り替え（AnimatePresence使用）:

| フェーズ | 時間 | 内容 |
|---------|------|------|
| `quiz` | ユーザー操作 | 質問表示・回答・分岐 |
| `analyzing` | 2.5秒 | 解析演出（回答サマリー+「わかりました！」） |
| `reveal` | 3.5秒 | 結果Reveal（きぶんくんtada+ジャンル名） |
| `detail` | ユーザー操作 | 詳細（Q4チップ、レストラン検索、シェア） |

### 自動位置情報取得
detailフェーズに入った時点でGeolocation APIを呼び出し、位置情報が取得できればレストラン検索を自動開始。拒否された場合はボタン押下UIにフォールバック。

## 19. v1 → v2 変更点サマリー

| 項目 | v1 | v2 |
|------|----|----|
| 質問方式 | 5問固定 → 4軸スコアリング | **分岐ツリー**(2〜3問でエンドポイント到達) |
| ジャンル数 | 16 | **20ジャンル + 30+結果パターン** |
| マスコット | なし | **きぶんくん**（5表情+7アニメーション） |
| 結果演出 | シンプル表示 | **3段階Reveal**(解析中→ズバリ！→詳細) |
| お店絞り込み | genre/keywordのみ | **Q4チップ + 予算 + 5段階フォールバック** |
| ページ構成 | `/quiz` → `/result` | **`/play` 1ページ内で切替** |
| トップ画面 | 複数セクション | **1画面完結**(きぶんくん+CTA+絵文字マーキー) |
| テーマカラー | 固定 | **ルートごとに8種類の背景テーマ** |

## 20. 今後の拡張候補

- **画像保存機能:** 結果カードをPNG/webpでダウンロード
- **動的OGP:** 結果ページごとにジャンル名入りOGP画像を生成
- **紙吹雪エフェクト:** canvas-confettiによるReveal演出強化
- **Lottieアニメーション:** きぶんくんをパーツ分解→After Effects→Lottie化
- **PWA対応:** ホーム画面追加、オフライン対応
- **時間帯・季節チューニング:** 冬は鍋系、金曜夜は飲み系の重みを自動調整
- **友達比較機能:** 2人分の結果を並べて食の相性を表示
