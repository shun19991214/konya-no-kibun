## 5. 質問設計

### 設計方針
- 「気分で決まる」コンセプトに沿い、感情・感覚にフォーカス
- 食ジャンルを直接連想させない聞き方で「正解を予想して選ぶ」を防ぐ
- 各質問は担当するスコア軸を明確に分離（軸の独立性確保）

### 5問の質問

| # | 質問文 | サブテキスト | 選択肢 | 主担当軸 |
|---|--------|------------|--------|---------|
| Q1 | 今日は誰と食べる？ | シチュエーションで変わるよね | ひとり🙋 / 恋人と💑 / 友達と👯 / 家族と👨‍👩‍👧‍👦 | casualFormal |
| Q2 | 今夜の気分に近いのは？ | 直感で選んでね | パワーチャージ💪 / 癒し☕ / 特別な時間✨ / いつもと違う🌍 | adventurous, wafuYofu |
| Q3 | 今日の体の感覚は？ | 体の声を聞いてみて | がっつり🔥 / 軽め🌿 / 辛い🌶️ / 温かい♨️ | heavyLight, wafuYofu |
| Q4 | お酒は飲みたい？ | 今夜のテンションは？ | 飲みたい🍺 / 飲まない🚗 / どちらでも🤷 | コンテキストペナルティ入力 |
| Q5 | お店に求めるのは？ | 最後の決め手を選んでね | サクッと⚡ / バランス👌 / 奮発💎 / 満腹🍚 | casualFormal, heavyLight |

## 6. スコアリングシステム

### 6.1 4つのスコア軸

| 軸 | 負(-) | 正(+) | スコア範囲 |
|----|-------|-------|----------|
| heavyLight | ヘビー・がっつり | ライト・さっぱり | 約 -10 〜 +5 |
| wafuYofu | 和風 | 洋風・エスニック | 約 -6 〜 +6 |
| casualFormal | カジュアル | フォーマル・おしゃれ | 約 -9 〜 +9 |
| adventurous | 定番・安心 | 冒険・新しいもの | 約 -5 〜 +6 |

### 6.2 マッチングアルゴリズム

**重み付きユークリッド距離:**

```
距離 = √( w₁(s₁-i₁)² + w₂(s₂-i₂)² + w₃(s₃-i₃)² + w₄(s₄-i₄)² )
```

- `s`: ユーザーの最終スコア
- `i`: ジャンルの理想スコア (ideal)
- `w`: 軸ごとの弁別重み (weight)
- **距離が小さいほどマッチ度が高い** → 上位3ジャンルを返却

### 6.3 コンテキストペナルティ/ボーナス

スコアリングだけでは防げない不自然な結果を補正する仕組み。
**正の値 = ペナルティ（距離を遠ざける）、負の値 = ボーナス（距離を近づける）**

## 8. ホットペッパーグルメAPI連携

### エンドポイント
`http://webservice.recruit.co.jp/hotpepper/gourmet/v1/`

### APIルート (app/api/restaurants/route.ts)

| パラメータ | 型 | 必須 | 説明 |
|----------|---|------|------|
| lat | string | △ | 緯度（lat/lngまたはkeywordのいずれか必須） |
| lng | string | △ | 経度 |
| range | string | × | 検索範囲 1-5（デフォルト: 3） |
| genre | string | △ | ホットペッパージャンルコード |
| keyword | string | △ | フリーテキスト検索 |

### 検索範囲（移動手段マッピング）

| 移動手段 | range | 距離 | 段階的拡大 |
|---------|-------|------|-----------|
| 徒歩🚶 | 2 | 500m | → 3 → 4 → 5 |
| 自転車🚲 | 3 | 1km | → 4 → 5 |
| 電車🚃 | 4 | 2km | → 5 |
| 車🚗 | 5 | 3km | - |

結果が3件未満の場合、自動的にrangeを段階的に拡大。

### エラーハンドリング
- ホットペッパーAPIはエラー時もHTTP 200を返すため、レスポンスボディ内の`results.error`で判定
- 認証エラー(code: 2000)は401を返却
- APIキーは`process.env.HOTPEPPER_API_KEY`（サーバーサイドのみ）

### ガイドライン準拠
- クレジット表記: ホットペッパーバナー画像(88x35px) + テキストリンク
- 画像利用時の「画像提供：ホットペッパー グルメ」表記
- 飲食店から対価を得るビジネスでの利用禁止
